
## Adapter Pattern

### Définition

Le **Adapter Pattern** est un pattern structurel qui permet de faire communiquer deux classes ayant des interfaces incompatibles.

L'Adapter agit comme un intermédiaire entre le code client et une classe existante.

### Adapter Design Pattern

1. **Client** → utilise l’interface qu’il connaît.
2. **Target** → interface attendue par le client.
3. **Adaptee** → classe existante avec une interface incompatible.
4. **Adapter** → fait le lien entre `Target` et `Adaptee`.

## Decorator Pattern

### Définition

Le **Decorator Pattern** est un design pattern structurel qui permet d’ajouter dynamiquement des fonctionnalités à un objet sans modifier sa classe d’origine.
